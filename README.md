# Trabalho final ME720/MI419 — Modelos lineares mistos

Trabalho final das disciplinas ME720/MI419 (UNICAMP). Usa o pacote `skewlmm`
para ajustar modelos lineares mistos com distribuições normal e de caudas
pesadas/assimétricas a dados longitudinais, como o peso de camundongos por
tratamento ao longo das semanas (`miceweight`).

O código compara estruturas de dependência (independência condicional, AR(1) e
DEC) por critérios de informação e gera os gráficos de trajetórias por
tratamento.

## Como reproduzir

Abra `Codigo_Trab_Final_ME720_Rodrigo_Caldiron.Rmd` no RStudio, instale
`skewlmm` e `tidyverse` e execute o *knit*.
